# Star Wars theme for Eitr

A dark [Eitr](https://eitr.info) theme with Star Wars art: lightsaber red on deep space, with 8 wallpapers.

![Preview](star-wars/preview.png)

## Install

Open the Eitr Store, choose Themes, and search for Star Wars.
